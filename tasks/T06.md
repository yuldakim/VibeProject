# T06. discord_notifier.py 기본 골격 및 Webhook 연결

## 목표
Discord Webhook으로 메시지를 보낼 수 있는 최소 기능을 만든다.

## 작업 내용
- Discord 채널에서 Webhook URL 발급, .env에 DISCORD_WEBHOOK_URL 추가
- discord_notifier.py: send_message(content) 기본 텍스트 전송 함수
- requests로 POST 후 상태코드 확인

## 완료 조건
- [ ] 테스트 메시지가 실제 Discord 채널에 도착
- [ ] 실패 시(잘못된 URL 등) 에러가 예외로 처리되고 죽지 않음
