# T07. Discord Embed 카드 메시지 포맷 구성

## 목표
최신 알람 정보를 보기 좋은 Embed 카드로 전송하고 대시보드 링크를 포함한다.

## 작업 내용
- send_alarm_embed(alarm: dict, dashboard_url: str) 함수 작성
- Embed 필드: facility_name, parameter_name, current_value/threshold_value, alarm_type, ai_opinion 요약
- 카드 하단에 Vercel 배포 URL 링크(버튼/필드) 포함
- get_alarm_logs()의 최신 1건을 사용해 실제 전송 테스트

## 완료 조건
- [ ] Discord에 Embed 카드가 필드 포함하여 정상 표시
- [ ] 카드에 Vercel URL 링크 클릭 가능
