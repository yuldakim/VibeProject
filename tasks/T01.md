# T01. Supabase 프로젝트 생성 및 접속키 발급

## 목표
Supabase 계정/프로젝트를 생성하고 앱에서 사용할 접속 정보를 확보한다.

## 작업 내용
- supabase.com에서 신규 프로젝트 생성 (리전: 가까운 곳)
- Project Settings > API에서 Project URL, anon public key 확인
- DB 비밀번호 별도 보관

## 완료 조건
- [ ] Project URL 확보
- [ ] anon key 확보
- [ ] 자격 정보를 안전한 곳(비밀 메모 등)에 임시 기록 — 코드/git에는 커밋 금지
