# T10. 이상 발생 리스트 테이블 시각화

## 목표
alarm_logs 데이터를 표 형태로 보여주고 행을 선택할 수 있게 한다.

## 작업 내용
- st.dataframe 또는 st.data_editor로 리스트 표시 (주요 컬럼만: 발생시각, 설비, 파라미터, 현재값/임계값, 유형)
- 행 선택 기능(streamlit 최신 버전의 selection, 없으면 selectbox로 alarm_id 선택) 구현
- 선택된 행을 세션 상태에 저장 (T11에서 사용)

## 완료 조건
- [ ] 리스트에 mock 데이터 2건 이상 표시
- [ ] 특정 행 선택 시 세션 상태 값이 갱신됨
