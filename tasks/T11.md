# T11. 파라미터 선택 UI 구현

## 목표
선택된 알람 행을 기준으로 조회할 파라미터를 사용자가 고를 수 있게 한다.

## 작업 내용
- T10에서 선택된 행의 facility_name/parameter_name을 기본값으로 노출
- 필요 시 동일 설비의 다른 파라미터도 selectbox로 선택 가능하게 구성
- 선택값을 세션 상태에 저장 (T12에서 사용)

## 완료 조건
- [ ] 리스트에서 행을 바꾸면 파라미터 선택 UI도 갱신됨
- [ ] 선택값이 다음 단계(차트)에 정상 전달됨
