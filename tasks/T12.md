# T12. 시계열 Plotly 차트 구현 (임계치 라인 포함)

## 목표
선택된 파라미터의 시계열 값을 Plotly 차트로 보여주고 임계치를 수평선으로 표시한다.

## 작업 내용
- 선택된 파라미터에 해당하는 시계열 데이터 준비 (mock 데이터가 단일 시점이면, 시연용으로 시간축 더미 확장 또는 현재 1포인트만 표시)
- plotly.graph_objects로 line chart 생성
- threshold_value 기준 add_hline으로 수평 기준선 추가 (색상으로 상한/하한 구분)
- app.py에 st.plotly_chart로 렌더링

## 완료 조건
- [ ] 차트에 실제값 라인 + 임계치 수평선이 함께 표시됨
- [ ] 파라미터 선택 변경 시 차트가 갱신됨
