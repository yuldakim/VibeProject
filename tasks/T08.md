# T08. app.py 대시보드 기본 레이아웃 구성

## 목표
Streamlit 앱의 뼈대를 만들고 데이터 로딩 함수(T04/T05)를 연결한다.

## 작업 내용
- app.py: st.set_page_config, 타이틀
- 사이드바 or 상단에 새로고침/필터 영역 자리 배치
- get_alarm_logs() 호출 결과를 세션에 로드
- `streamlit run app.py`로 로컬 구동 확인
