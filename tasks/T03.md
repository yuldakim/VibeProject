# T03. Python 프로젝트 환경 셋업

## 목표
로컬 개발 환경과 의존성 파일의 초안을 마련한다.

## 작업 내용
- venv 생성 및 활성화
- requirements.txt 초안 작성: streamlit, supabase, plotly, python-dotenv, requests, pandas
- .env.example 작성 (SUPABASE_URL, SUPABASE_KEY, DISCORD_WEBHOOK_URL)
- .gitignore에 .env 추가

## 완료 조건
- [ ] venv에서 `pip install -r requirements.txt` 성공
- [ ] .env.example 커밋, 실제 .env는 gitignore 처리
