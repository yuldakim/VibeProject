# T15. 환경변수 설정 (.env / Vercel Environment Variables)

## 목표
민감 정보를 코드에서 분리하고 로컬/배포 환경 모두에서 동작하게 한다.

## 작업 내용
- 로컬 .env에 SUPABASE_URL, SUPABASE_KEY, DISCORD_WEBHOOK_URL 설정
- Vercel 프로젝트 Settings > Environment Variables에 동일 키 등록
- 코드에서 python-dotenv/os.environ으로 일관되게 읽어오는지 점검

## 완료 조건
- [ ] 로컬 실행 시 .env 값으로 정상 동작
- [ ] Vercel Environment Variables 등록 완료 (배포 전 확인)
